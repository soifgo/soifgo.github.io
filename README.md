## 🚀 Flagship Projects

### 1. SoifGo — Android IoT & Hardware Controller
An advanced open-source Android application built with Basic4Android (B4A) designed to bridge mobile interfaces with hardware systems.
* **Core Features:** Bluetooth Serial (SPP), MQTT client, HTTP REST API, phone sensors, speech recognition, and a robust WebView JavaScript bridge (`window.soifgo`).
* **Specialized Tools:** Includes modules for CNC machine G-code control (**CMI209**) and WS2811/WS2812 pixel LED sign design (**RANGMANG**).
* **Links:** [Official Website](https://soifgo.github.io/soifgo/) | [Developer Docs](https://soifgo.github.io/soifgo/docs.html) | [AI Context Reference](soifgo/SOIFGO_AI_CONTEXT.md)

### 2. AnyScan209 — Geophysical 2D/3D Mapping Software
A professional-grade independent geophysical Android application engineered to transform raw internal magnetometer or external Bluetooth sensor data into real-time 2D and 3D subsurface visualization maps.
* **Core Features:** Internal Magnetic Sensor Mode (with DC/AC current estimation capabilities), External Bluetooth Sensor Mode, real-time 3D topographical rendering, and flexible project grid management.
* **Downloads:** [Uptodown](https://anyscan209.en.uptodown.com/android) | [APKPure](https://apkpure.com/anyscan209/any.scan_209/download/1.86)
* **Links:** [Project Guide](https://soifgo.github.io/AnyScan209/) | [AI Context Reference](AnyScan209/AnyScan209_AI_CONTEXT.md)
