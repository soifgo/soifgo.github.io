  8. የAI ኮድ ይለጥፉ: ምናሌውን እንደገና ይክፈቱ እና የWebView አርትዖት ማያ ገጽን ለመክፈት Edit ይምረጡ። ከAI ረዳት ያገኙትን የHTML ኮድ እዚህ ይለጥፉ። ሁሉንም መርጠው በእጅ መለጠፍ ይችላሉ፣ ወይም ምናሌውን ከፍተው የመጨረሻውን አማራጭ Select All and Paste መምረጥ ይችላሉ፣ ይህም ኮዱን በራስ-ሰር ይተካል።
  9. ኮዱን ያሂዱ: አሁን በማያ ገጹ አናት ላይ ያለውን ቢጫ አዝራር (Close) ይንኩ። ኮድዎ ይሰራል። ገጹን መዝጋት ይችላሉ፣ እና መሣሪያውን ለመጀመር በእያንዳንዱ ጊዜ አዝራርዎን መንካት ብቻ ነው የሚያስፈልግዎት።

ወደፊት ከAI ረዳት አዲስ ኮድ ሲያገኙ፣ ወደ ተመሳሳዩ ገጽ ብቻ ይሂዱ፣ Edit ይንኩ፣ በWebView አርትዖት ማያ ገጽ ላይ Select All and Paste ይምረጡ፣ እና ቢጫውን አዝራር እንደገና ይንኩ። File Explorer የሚጠቀሙ ከሆነ ስልክዎ ያንን ክፍል ላይደግፍ ይችላል፤ በዚያ ሁኔታ ተስማሚ የፋይል አቀናባሪ በስልክዎ ላይ መጫን ይመከራል።

በእያንዳንዱ ገጽ 40 የተለያዩ የድር መተግበሪያዎች

በእያንዳንዱ ገጽ ላይ 40 የተለያዩ የድር መተግበሪያዎች ሊኖሩዎት ይችላሉ። በእያንዳንዱ ጊዜ AI ረዳት እንዲፈጥራቸው መጠየቅ አያስፈልግዎትም፣ እና ከመስመር ውጭ ሊጠቀሙባቸው ይችላሉ። እንዲሁም ለባልደረቦች፣ ለጓደኞች ወይም ለተሳታፊዎች እንዲያወርዱና እንዲያሂዱ ሊልኩላቸው ይችላሉ።

የSoifGo ባህሪያት

🌐 ሙሉ WebView

ዘመናዊ የአሳሽ ሞተር፦ Canvas፣ SVG፣ WebGL እና እንደ Chart.js፣ D3 እና Three.js ያሉ ቤተ-መጻሕፍት ለቻርቶች፣ ማስመሰያዎችና 3D ምስሎች።

🧩 ክላሲክ ሁነታ

ዝግጁ አዝራሮችና ተንሸራታቾች፣ ያለ ምንም ኮድ፣ ለቀላል ቁጥጥርና ምናሌዎች።

💾 አካባቢያዊ ማከማቻ

መተግበሪያው ከተዘጋ በኋላም ቢሆን በlocalStorage ውሂብ ያስቀምጡ።

🟢 የስልክ ዳሳሾች

የአካባቢ ብርሃን፣ እንቅስቃሴ (አክሰለሮሜትር) እና ማግኔቶሜትር፣ በቀጥታ።

🎤 ማይክሮፎን እና የድምፅ ማወቂያ

ንግግርን ወደ ጽሑፍ ይለውጡ እና በመሣሪያዎችዎ ውስጥ ይጠቀሙበት ወይም ወደ መሣሪያዎች ይላኩት።

🔵 ተከታታይ ብሉቱዝ

በHC-05፣ HC-06፣ JDY-31፣ BLE፣ Arduino፣ ESP32 እና Raspberry Pi ጽሑፍ ይላኩ እና ይቀበሉ።

🟣 MQTT ደንበኛ

ከማንኛውም ደላላ (tcp ወይም ssl) ጋር ይገናኙ፣ ያትሙ እና ይመዝገቡ፣ እና የግንኙነት ሁኔታን ይመልከቱ።

🟠 HTTP API

JSON ወደ ማንኛውም አድራሻ ይላኩ፣ እና ከምላሹ እሴቶችን ተቀብለው ያውጡ።

ምን መፍጠር ይችላሉ?

  • ካልኩሌተሮችና ልዩ የስሌት መሣሪያዎች
  • ግራፎችን መሳል፣ ማስመሰያዎችና የውሂብ ምስላዊ መግለጫ
  • ተግባቦታዊ የማስተማሪያ መሣሪያዎች፣ ልምምዶችና ፈተናዎች
  • 3D ምስሎችና የሳይንስ መሣሪያዎች
  • ለሥራዎ የተበጁ ዳሽቦርዶችና በይነ ገጾች
  • LED፣ ሞተር፣ ሪሌይና ሮቦቶችን በብሉቱዝ መቆጣጠር፣ እንዲሁም የብሉቱዝ–MQTT ድልድዮች
  • መሣሪያዎችን በድምፅ መቆጣጠር

በተደጋጋሚ የሚጠየቁ ጥያቄዎች

SoifGo ለArduino እና ለኤሌክትሮኒክስ ብቻ ነው?

አይደለም። የሃርድዌር ግንኙነት ከባህሪያቱ አንዱ ብቻ ነው። መሣሪያዎችዎ HTML ስለሆኑ፣ በድር ጣቢያ ላይ የሚሰራ ማንኛውም ነገር፣ ለምሳሌ ስሌቶች፣ ቻርቶች፣ ማስመሰያዎች እና የማስተማሪያ መሣሪያዎች በSoifGo ውስጥም ይሰራል።

SoifGo ነፃ ነው?

አዎ። ነፃ ነው፣ ማስታወቂያ የለውም፣ እና በመተግበሪያው ውስጥ ግዢ የለውም።

ያለ ኢንተርኔት ይሰራል?

የHTML መሣሪያዎች፣ ብሉቱዝ እና የስልክ ዳሳሾች ያለ ኢንተርኔት ይሰራሉ። MQTT እና HTTP ብቻ የኢንተርኔት ወይም የአውታረ መረብ ግንኙነት ይፈልጋሉ።

ከየትኛው ሃርድዌር ጋር ይስማማል?

ብሉቱዝ SPP/BLE (እንደ HC-05 እና HC-06)፣ MQTT ወይም HTTP REST ከሚጠቀም ማንኛውም መሣሪያ ጋር፣ Arduino፣ ESP32፣ ESP8266 እና Raspberry Piን ጨምሮ።

ለመጀመር ምን ያስፈልገኛል?

መሠረታዊ የHTML እውቀት በቂ ነው። ያለ እሱም ቢሆን፣ የሚፈልጉትን ለAI ረዳት ገልጸው የHTML ኮድ ማግኘት ይችላሉ። አጋዥ ስልጠናዎችና ዝግጁ ምሳሌዎች በዋናው ገጽ ላይ አሉ።

SoifGo እንዴት ይነበባል፣ ሌሎች ስሞቹስ ምንድን ናቸው?

SoifGo ብዙውን ጊዜ “soif-go” ተብሎ ይነበባል፣ ሰዎች ግን Soif Go፣ Swift Go፣ Swiftgo፣ Soyf Go፣ Sayf Go፣ Swaif Go ወይም So if go ብለውም ይናገራሉ ወይም ይጽፋሉ። እነዚህ ሁሉ ስሞች ወደ አንድ ነፃ የአንድሮይድ መተግበሪያ፣ SoifGo ያመለክታሉ። ከSwift የፕሮግራሚንግ ቋንቋ ጋር ግንኙነት የለውም።

ለመጀመር ዝግጁ ነዎት?

ዋናው ገጽ ከማውረጃ፣ ከአጋዥ ስልጠናዎችና ከሰነዶች ጋር ይከፈታል።
