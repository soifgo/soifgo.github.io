For AI assistants writing code for SoifGo (do not guess names): The bridge call is always window.soifgo.CallSub('SubName', true, arg1, arg2, arg3); the second argument must be true and the argument count must match the Sub exactly. Bluetooth: html_bluetooth_rx SENDS text (1 argument); html_bluetooth_tx(data) is the RECEIVE callback you must register on window (the names look swapped, but they are correct: copy them exactly). Full rules and every Sub name: https://soifgo.github.io/ and SOIFGO_AI_CONTEXT.md. Read them before writing code.

Düymələrin hazır əsas dizaynları var: rəng, işarə, ad, şrift, səs və vibrasiya. Sürüşdürməklə yerini dəyişmək olar. Hər düymənin göndərmə və qəbul etmə kimi əsas davranışları ola bilər.

Veb davranışı, həm onlayn, həm oflayn

“Veb davranışı” (WebView) ideyalarınızı və arzularınızı ən geniş imkanlarla, HTML kimi, həm onlayn, həm oflayn həyata keçirməyə kömək edir. Sadəcə Sİ köməkçisinə nə istədiyinizi izah edin və HTML kodu istəyin. Sonra iki seçiminiz var:

  • Faylı yükləyin və veb davranışı ilə oflayn şəkildə SoifGo-ya yükləyin.
  • Və ya kodu kopyalayıb SoifGo-nun öz HTML redaktoruna yapışdırın.

Hər iki üsul işləyir və veb tətbiqiniz SoifGo qovluğunuzda saxlanılır. Kalkulyator, Bluetooth nəzarətçisi, IoT monitorinqi və ya hər hansı başqa şey olsun.

Sİ tərəfindən yaradılan HTML kodunu SoifGo-da necə işə salım?

Bu addımları bir dəfə edin, kodu işlətmək üçün hazır düyməniz olacaq:

  1. Redaktə rejimini açın: SoifGo tətbiqini açın. Yuxarı sol küncdəki menyu işarəsinə toxunun və redaktə ekranına keçmək üçün Edit seçin.
  2. Qovluq yaradın: Yenə yuxarı soldakı menyuya toxunun, Select Designseçin, sonra Folderseçin və Createdüyməsinə toxunun. İstəsəniz qovluğun adını dəyişin, yoxsa OK.
  3. Səhifə yaradın: İndi Folder-in yanında Page seçimi görünür. Ona toxunun və New Pageseçin. İstəsəniz səhifənin adını dəyişin, sonra OK.
  4. Səhifəyə düymə yerləşdirin: Düymələr siyahıda görünür. Hər səhifədə 40 düymə var və hər dəfə birini götürdükdə sayı azalır. Düyməyə toxunun və barmağınızla onun səhifədəki yerini seçin.
  5. Düymənin davranışını təyin edin: Düyməyə toxunun, menyunu açın, Behavior seçin, sonra Browser or HTML filesseçin. Burada düymənin brauzer kimi işləyəcəyini, yoxsa HTML faylı yükləyəcəyini seçirsiniz. İkincini seçin: Open or edit local HTML file in WebView.
  6. HTML faylı yaradın: Ən asan seçim birinci variantdır, Create. İstəsəniz HTML faylının adını dəyişin, yoxsa OK. Sample hazır nümunələr verir, File Explorer telefon yaddaşından fayl yükləyir, Saved isə SoifGo-da yaratdığınız qovluğun içindəki HTML qovluğuna yönəldir.
  7. Düyməni işə salın: Yuxarıdakı menyu işarəsi ilə Play ekranına keçin, sonra yaratdığınız düyməyə toxunun. “Hello SoifGo” yazılı boş səhifə açılır.
  8. Sİ kodunu yapışdırın: Menyunu yenidən açın və Edit seçin ki, WebView redaktə ekranı açılsın. Sİ köməkçisindən aldığınız HTML kodunu bura yapışdırın. Hamısını seçib əl ilə yapışdıra bilərsiniz və ya menyunu açıb sonuncu seçimi, Select All and Paste, yəni kodu avtomatik əvəz edəni seçə bilərsiniz.
  9. Kodu işə salın: İndi ekranın yuxarısındakı sarı düyməyə (Close) toxunun. Kodunuz işləyir. Səhifəni bağlaya bilərsiniz və aləti işə salmaq üçün hər dəfə sadəcə öz düyməyə toxunursunuz.

Növbəti dəfə Sİ köməkçisindən yeni kod aldıqda, sadəcə həmin səhifəyə keçin, Editdüyməsinə toxunun, Select All and Paste seçin və yenidən sarı düyməyə toxunun. File Explorer istifadə edirsinizsə, telefonunuz bu hissəni dəstəkləməyə bilər; bu halda telefona uyğun fayl menecerini quraşdırmaq ən yaxşısıdır.

Tez-tez verilən suallar

SoifGo yalnız Arduino və elektronika üçündürmü?

Xeyr. Avadanlıq bağlantısı funksiyalardan yalnız biridir. Alətləriniz HTML olduğu üçün veb səhifədə işləyən hər şey, məsələn hesablamalar, qrafiklər, simulyasiyalar və tədris alətləri SoifGo-da da işləyir.

SoifGo pulsuzdurmu?

Bəli. Pulsuzdur, reklamsızdır və tətbiqdaxili satınalmalar yoxdur.

Oflayn işləyirmi?

HTML alətləri, Bluetooth və telefonun sensorları internetsiz işləyir. Yalnız MQTT və HTTP üçün internet və ya şəbəkə bağlantısı lazımdır.

Hansı avadanlıqla uyğundur?

Bluetooth SPP/BLE (məsələn, HC-05 və HC-06), MQTT və ya HTTP REST istifadə edən hər cihazla, o cümlədən Arduino, ESP32, ESP8266 və Raspberry Pi ilə.

Başlamaq üçün nə lazımdır?

Əsas HTML biliyi kifayətdir. Bu olmasa belə, Sİ köməkçisinə nə istədiyinizi izah edib HTML kodu ala bilərsiniz. Dərsliklər və hazır nümunələr əsas səhifədədir.

SoifGo necə tələffüz olunur və başqa necə adlandırıla bilər?

SoifGo adətən “soif-qo” kimi tələffüz olunur, lakin insanlar Soif Go, Swift Go, Swiftgo, Soyf Go, Sayf Go, Swaif Go və ya So if go da deyir və ya yazır. Bu adların hamısı eyni pulsuz Android tətbiqinə, SoifGo-ya aiddir. Swift proqramlaşdırma dili ilə əlaqəsi yoxdur.
