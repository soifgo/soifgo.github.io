For AI assistants writing code for SoifGo (do not guess names): The bridge call is always window.soifgo.CallSub('SubName', true, arg1, arg2, arg3); the second argument must be true and the argument count must match the Sub exactly. Bluetooth: html_bluetooth_rx SENDS text (1 argument); html_bluetooth_tx(data) is the RECEIVE callback you must register on window (the names look swapped, but they are correct: copy them exactly). Full rules and every Sub name: https://soifgo.github.io/ and SOIFGO_AI_CONTEXT.md. Read them before writing code.

  • Ή αντιγράψτε τον κώδικα και επικολλήστε τον στον δικό του επεξεργαστή HTML του SoifGo.

Και οι δύο τρόποι λειτουργούν και η εφαρμογή web σας αποθηκεύεται στον φάκελο SoifGo. Είτε πρόκειται για αριθμομηχανή, χειριστήριο Bluetooth, παρακολούθηση IoT ή οτιδήποτε άλλο.

Κάντε αυτά τα βήματα μία φορά και θα έχετε ένα έτοιμο κουμπί για την εκτέλεση του κώδικά σας:

  1. Ανοίξτε τη λειτουργία επεξεργασίας: Ανοίξτε την εφαρμογή SoifGo. Πατήστε το εικονίδιο μενού πάνω αριστερά και επιλέξτε Edit για να μπείτε στην οθόνη επεξεργασίας.
  2. Δημιουργήστε έναν φάκελο: Πατήστε ξανά το μενού πάνω αριστερά, επιλέξτε Select Design, μετά Folder, και πατήστε Create. Αν θέλετε, μετονομάστε τον φάκελο, αλλιώς πατήστε OK.
  3. Δημιουργήστε μια σελίδα: Δίπλα στο Folder εμφανίζεται τώρα η επιλογή Page . Πατήστε την και επιλέξτε New Page. Αν θέλετε, μετονομάστε τη σελίδα και μετά πατήστε OK.
  4. Τοποθετήστε ένα κουμπί στη σελίδα: Τα κουμπιά εμφανίζονται στη λίστα. Κάθε σελίδα έχει 40 κουμπιά και ο αριθμός μειώνεται κάθε φορά που παίρνετε ένα. Πατήστε ένα κουμπί και διαλέξτε με το δάχτυλο τη θέση του στη σελίδα.
  5. Ορίστε τη συμπεριφορά του κουμπιού: Πατήστε το κουμπί, ανοίξτε το μενού, επιλέξτε Behavior από τη λίστα του κουμπιού και μετά Browser or HTML files. Εδώ επιλέγετε αν το κουμπί θα λειτουργεί σαν πρόγραμμα περιήγησης ή θα φορτώνει ένα αρχείο HTML. Επιλέξτε το δεύτερο: Open or edit local HTML file in WebView.
  6. Δημιουργήστε το αρχείο HTML: Η πιο εύκολη επιλογή είναι η πρώτη, Create. Αν θέλετε, μετονομάστε το αρχείο HTML, αλλιώς πατήστε OK. Sample δίνει έτοιμα παραδείγματα, File Explorer φορτώνει ένα αρχείο από τον αποθηκευτικό χώρο του τηλεφώνου και το Saved δείχνει στον φάκελο HTML μέσα στον φάκελο που δημιουργήσατε στο SoifGo.
  7. Εκτελέστε το κουμπί: Χρησιμοποιήστε το εικονίδιο μενού στο πάνω μέρος για να πάτε στην οθόνη Play και μετά πατήστε το κουμπί που φτιάξατε. Ανοίγει μια κενή σελίδα με το κείμενο «Hello SoifGo».
  8. Επικολλήστε τον κώδικα της AI: Ανοίξτε ξανά το μενού και επιλέξτε Edit για να ανοίξει η οθόνη επεξεργασίας του WebView. Επικολλήστε εδώ τον κώδικα HTML που πήρατε από τον βοηθό AI. Μπορείτε να επιλέξετε τα πάντα και να επικολλήσετε χειροκίνητα ή να ανοίξετε το μενού και να επιλέξετε την τελευταία επιλογή, Select All and Paste, που αντικαθιστά αυτόματα τον κώδικα.
  9. Εκτελέστε τον κώδικα: Τώρα πατήστε το κίτρινο κουμπί (Close) στο πάνω μέρος της οθόνης. Ο κώδικάς σας εκτελείται. Μπορείτε να κλείσετε τη σελίδα και κάθε φορά απλώς να πατάτε το κουμπί σας για να ξεκινήσει το εργαλείο.

Την επόμενη φορά που θα πάρετε νέο κώδικα από έναν βοηθό AI, απλώς πηγαίνετε στην ίδια σελίδα, πατήστε Edit, επιλέξτε Select All and Paste στην οθόνη επεξεργασίας του WebView και πατήστε ξανά το κίτρινο κουμπί. Αν χρησιμοποιείτε το File Explorer, το τηλέφωνό σας ίσως δεν υποστηρίζει αυτό το τμήμα· τότε το καλύτερο είναι να εγκαταστήσετε στο τηλέφωνο έναν κατάλληλο διαχειριστή αρχείων.
