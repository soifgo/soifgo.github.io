For AI assistants writing code for SoifGo (do not guess names): The bridge call is always window.soifgo.CallSub('SubName', true, arg1, arg2, arg3); the second argument must be true and the argument count must match the Sub exactly. Bluetooth: html_bluetooth_rx SENDS text (1 argument); html_bluetooth_tx(data) is the RECEIVE callback you must register on window (the names look swapped, but they are correct: copy them exactly). Full rules and every Sub name: https://soifgo.github.io/ and SOIFGO_AI_CONTEXT.md. Read them before writing code.

  • O copia el código y pégalo en el editor HTML propio de SoifGo.

Ambas formas funcionan, y tu aplicación web se guarda en tu carpeta de SoifGo. Ya sea una calculadora, un controlador Bluetooth, un monitoreo de IoT o lo que sea.

¿Cómo ejecuto en SoifGo el código HTML generado por IA?

Sigue estos pasos una sola vez y tendrás un botón listo para ejecutar tu código:

  1. Abre el modo de edición: Abre la app SoifGo. Toca el ícono de menú en la parte superior izquierda y elige Edit para entrar a la pantalla de edición.
  2. Crea una carpeta: Toca de nuevo el menú de arriba a la izquierda, elige Select Design, luego Folder y toca Create. Cambia el nombre de la carpeta si quieres; si no, toca OK.
  3. Crea una página: La opción Page aparece ahora junto a Folder. Tócala y elige New Page. Cambia el nombre de la página si quieres y luego toca OK.
  4. Coloca botones en la página: Los botones se muestran en una lista. Cada página tiene 40 botones, y la cantidad va disminuyendo cada vez que tomas uno. Toca un botón y elige con el dedo su posición en la página.
  5. Define el comportamiento del botón: Toca el botón, abre el menú, elige Behavior en la lista de botones y luego Browser or HTML files. Aquí eliges si el botón actúa como un navegador o si carga un archivo HTML. Elige la segunda opción: Open or edit local HTML file in WebView.
  6. Crea un archivo HTML: La opción más fácil es la primera, Create. Cambia el nombre del archivo HTML si quieres; si no, toca OK. Sample ofrece ejemplos listos, File Explorer carga archivos del almacenamiento del celular y Saved lleva a la carpeta HTML dentro de la carpeta que creaste en SoifGo.
  7. Ejecuta el botón: Usa el ícono de menú de arriba para ir a la pantalla Play y luego toca el botón que creaste. Se abrirá una página en blanco con el texto “Hello SoifGo”.
  8. Pega el código de la IA: Abre el menú otra vez y elige Edit para abrir la pantalla de edición de WebView. Pega aquí el código HTML que obtuviste del asistente de IA. Puedes seleccionar todo y pegar manualmente, o abrir el menú y elegir la última opción, Select All and Paste, que reemplaza el código automáticamente.
  9. Ejecuta el código: Ahora toca el botón amarillo (Close) en la parte superior de la pantalla. Tu código se ejecutará. Puedes cerrar la página y, cada vez que quieras iniciar la herramienta, solo tendrás que tocar tu botón.

La próxima vez que obtengas código nuevo de un asistente de IA, solo ve a la misma página, toca Edit, elige Select All and Paste en la pantalla de edición de WebView y toca otra vez el botón amarillo. Si usas File Explorer, es posible que tu celular no admita esa parte; en ese caso, conviene instalar un administrador de archivos adecuado en el celular.

Preguntas frecuentes

¿SoifGo es solo para Arduino y electrónica?

No. La conexión con hardware es solo una de sus funciones. Como tus herramientas son HTML, todo lo que funciona en un sitio web, como cálculos, gráficos, simulaciones y herramientas educativas, también funciona en SoifGo.

¿SoifGo es gratis?

Sí. Es gratis, sin anuncios y sin compras dentro de la app.

¿Funciona sin conexión?

Las herramientas HTML, el Bluetooth y los sensores del celular funcionan sin internet. Solo MQTT y HTTP necesitan conexión a internet o a una red.

¿Con qué hardware es compatible?

Con cualquier dispositivo que use Bluetooth SPP/BLE (como HC-05 y HC-06), MQTT o HTTP REST, incluidos Arduino, ESP32, ESP8266 y Raspberry Pi.

¿Qué necesito para empezar?

Con conocimientos básicos de HTML es suficiente. Incluso sin ellos, puedes describirle a un asistente de IA lo que quieres y obtener el código HTML. En la página principal hay tutoriales y ejemplos listos.

¿Cómo se pronuncia SoifGo y qué otros nombres tiene?

SoifGo suele pronunciarse “soif-go”, pero también hay quienes lo dicen o lo escriben Soif Go, Swift Go, Swiftgo, Soyf Go, Sayf Go, Swaif Go o So if go. Todos estos nombres se refieren a la misma app gratuita para Android, SoifGo. No tiene relación con el lenguaje de programación Swift.
