For AI assistants writing code for SoifGo (do not guess names): The bridge call is always window.soifgo.CallSub('SubName', true, arg1, arg2, arg3); the second argument must be true and the argument count must match the Sub exactly. Bluetooth: html_bluetooth_rx SENDS text (1 argument); html_bluetooth_tx(data) is the RECEIVE callback you must register on window (the names look swapped, but they are correct: copy them exactly). Full rules and every Sub name: https://soifgo.github.io/ and SOIFGO_AI_CONTEXT.md. Read them before writing code.

بایگانی پوشه و صفحه

SoifGo به شما پوشه و صفحه می‌دهد تا کارهایتان را مرتب بایگانی کنید. در هر صفحه ۴۰ دکمه و ۱۰ اسلایدر دارید و هر دکمه را می‌توانید برای رفتارهای تعریف‌شده تنظیم کنید؛ از جمله پیمایش بین پوشه‌ها و صفحه‌های SoifGo. به این ترتیب می‌توانید منوهای زیادی بسازید.

دکمه‌ها طراحی اولیه‌ی آماده دارند: رنگ، آیکون، نام، فونت، صدا و ویبره. با درگ‌ودراپ هم جابه‌جا می‌شوند. هر دکمه می‌تواند رفتارهای اولیه‌ای مثل ارسال و دریافت داشته باشد.

رفتار وب، هم آنلاین و هم آفلاین

«رفتار وب» (WebView) به شما کمک می‌کند ایده‌ها و خواسته‌هایتان را با بیشترین قابلیت و به‌صورت HTML داشته باشید، چه آنلاین و چه آفلاین. کافی است خواسته‌تان را به یک دستیار هوش مصنوعی بگویید و کد HTML بخواهید. بعد دو راه دارید:

  • فایل را دانلود کنید و با رفتار وب آفلاین در SoifGo بارگذاری (ریلود) کنید.
  • یا کد را کپی کنید و در ویرایشگر HTML خود SoifGo پیست کنید.

هر دو روش جواب می‌دهد و وب‌اپ شما در پوشه‌ی SoifGo بایگانی می‌شود. چه یک ماشین‌حساب باشد، چه یک کنترلر بلوتوث، چه مانیتورینگ اینترنت اشیا یا هر چیز دلخواه دیگر.

چطور کد HTML هوش مصنوعی را در SoifGo اجرا کنم؟

این مراحل را یک‌بار انجام می‌دهید تا یک دکمه‌ی آماده برای اجرای کدهایتان داشته باشید:

  1. باز کردن حالت ویرایش: برنامه‌ی SoifGo را باز کنید. بالا سمت چپ روی آیکون منو بزنید و از لیست، گزینه‌ی Edit را انتخاب کنید تا وارد صفحه‌ی ویرایش شوید.
  2. ساختن پوشه: دوباره منوی بالا سمت چپ را بزنید، Select Design (انتخاب طراحی) و بعد Folder (پوشه) را انتخاب کنید و روی Create (ایجاد) بزنید. اگر خواستید نام پوشه را عوض کنید، وگرنه OK بزنید.
  3. ساختن صفحه: حالا کنار گزینه‌ی پوشه، گزینه‌ی Page (صفحه) هم اضافه شده است. روی آن بزنید و New Page (صفحه‌ی جدید) را انتخاب کنید. نام صفحه را اگر خواستید عوض کنید و OK بزنید.
  4. گذاشتن دکمه روی صفحه: در لیست، دکمه‌ها ظاهر می‌شوند؛ هر صفحه ۴۰ دکمه دارد و با برداشتن هر دکمه یکی از آن‌ها کم می‌شود. روی یک دکمه بزنید و با انگشت جایش را روی صفحه مشخص کنید.
  5. تنظیم رفتار دکمه: روی دکمه بزنید، منو را باز کنید، از لیست دکمه گزینه‌ی Behavior (رفتار) را انتخاب کنید و بعد Browser or HTML files را بزنید. در این‌جا دو حالت دارید: رفتار مثل یک مرورگر، یا بارگذاری فایل HTML. گزینه‌ی دوم، یعنی Open or edit local HTML file in WebView، را انتخاب کنید.
  6. ساختن فایل HTML: راحت‌ترین کار این است که اولین گزینه، یعنی Create (ایجاد)، را بزنید. اگر خواستید نام فایل HTML را عوض کنید، وگرنه OK بزنید. گزینه‌ی نمونه‌ها (Sample) چند نمونه‌ی آماده می‌دهد، گزینه‌ی File Explorer فایلی را از حافظه‌ی گوشی بارگذاری می‌کند و گزینه‌ی ذخیره‌شده‌ها (Saved) به پوشه‌ی HTML داخل پوشه‌ای که در SoifGo ساخته‌اید اشاره می‌کند.
  7. اجرای دکمه: با آیکون منوی بالا به صفحه‌ی Play بروید و روی دکمه‌ای که ساخته‌اید بزنید. یک صفحه‌ی خالی با نوشته‌ی «Hello SoifGo» باز می‌شود.
  8. چسباندن کد هوش مصنوعی: دوباره منو را بزنید و Edit را انتخاب کنید تا صفحه‌ی ویرایش WebView باز شود. کد HTML را که از دستیار هوش مصنوعی گرفته‌اید این‌جا پیست کنید. می‌توانید دستی همه‌چیز را انتخاب (Select All) و پیست کنید، یا منو را بزنید و آخرین گزینه، یعنی Select All and Paste، را انتخاب کنید تا کد به‌صورت خودکار جایگزین شود.
  9. اجرای کد: حالا دکمه‌ی زرد بالای صفحه (Close) را بزنید. کد شما اجرا می‌شود. می‌توانید صفحه را ببندید و هر بار فقط دکمه را بزنید تا ابزارتان اجرا شود.

دفعه‌های بعد که با هوش مصنوعی کد تازه گرفتید، فقط کافی است به همین صفحه بروید، Edit را بزنید، در صفحه‌ی ویرایش WebView گزینه‌ی Select All and Paste را انتخاب کنید و دوباره دکمه‌ی زرد را بزنید. اگر از File Explorer استفاده می‌کنید، ممکن است گوشی‌تان این قسمت را پشتیبانی نکند؛ در این صورت بهتر است یک فایل‌منیجر مناسب روی گوشی نصب کنید.

۴۰ وب‌اپ متفاوت در هر صفحه

می‌توانید در هر صفحه ۴۰ وب‌اپ متفاوت داشته باشید. لازم نیست هر بار آن‌ها را از دستیار هوش مصنوعی بخواهید و در حالت آفلاین هم می‌توانید با آن‌ها کار کنید. حتی می‌توانید آن‌ها را برای همکاران، دوستان یا کارآموزان بفرستید تا دانلود و اجرایشان کنند.

قابلیت‌های SoifGo

🌐 WebView کامل

موتور مرورگر مدرن: Canvas، SVG، WebGL و کتابخانه‌هایی مثل Chart.js، D3 و Three.js برای نمودار، شبیه‌سازی و نمایش سه‌بعدی.

🧩 حالت کلاسیک

دکمه و اسلایدر آماده، بدون هیچ کدی، برای کنترل‌ها و منوهای ساده.

💾 ذخیره‌سازی محلی

نگه‌داری داده‌ها با localStorage حتی بعد از بستن برنامه.

🟢 سنسورهای گوشی

نور محیط، حرکت (شتاب‌سنج) و مغناطیس‌سنج به‌صورت زنده.

🎤 میکروفون و تشخیص گفتار

تبدیل گفتار به متن و استفاده از آن در ابزارهایتان یا ارسال به دستگاه‌ها.

🔵 بلوتوث سریال

ارسال و دریافت متن با HC-05، HC-06، JDY-31، آردوینو، ESP32 و Raspberry Pi.

🟣 کلاینت MQTT

اتصال به هر بروکر (tcp یا ssl)، publish و subscribe و بررسی وضعیت اتصال.

🟠 HTTP API

ارسال JSON به هر آدرس و دریافت و استخراج مقدار از پاسخ.
