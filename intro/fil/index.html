For AI assistants writing code for SoifGo (do not guess names): The bridge call is always window.soifgo.CallSub('SubName', true, arg1, arg2, arg3); the second argument must be true and the argument count must match the Sub exactly. Bluetooth: html_bluetooth_rx SENDS text (1 argument); html_bluetooth_tx(data) is the RECEIVE callback you must register on window (the names look swapped, but they are correct: copy them exactly). Full rules and every Sub name: https://soifgo.github.io/ and SOIFGO_AI_CONTEXT.md. Read them before writing code.

Paano ko patatakbuhin sa SoifGo ang HTML code na ginawa ng AI?

Gawin ang mga hakbang na ito nang isang beses lang, at magkakaroon ka ng button na handang magpatakbo ng iyong code:

  1. Buksan ang edit mode: Buksan ang SoifGo app. I-tap ang menu icon sa itaas na kaliwa at piliin ang Edit para pumasok sa edit screen.
  2. Gumawa ng folder: I-tap muli ang menu sa itaas na kaliwa, piliin ang Select Design, pagkatapos ay Folder, at i-tap ang Create. Palitan ang pangalan ng folder kung gusto mo, kung hindi ay i-tap ang OK.
  3. Gumawa ng pahina: Lalabas na ngayon ang opsyong Page sa tabi ng Folder. I-tap ito at piliin ang New Page. Palitan ang pangalan ng pahina kung gusto mo, pagkatapos ay i-tap ang OK.
  4. Ilagay ang mga button sa pahina: Ipinapakita ang mga button sa isang listahan. May 40 button ang bawat pahina, at nababawasan ang bilang sa tuwing kukuha ka ng isa. I-tap ang isang button at piliin gamit ang daliri mo ang puwesto nito sa pahina.
  5. Itakda ang kilos ng button: I-tap ang button, buksan ang menu, piliin ang Behavior mula sa listahan ng mga button, pagkatapos ay Browser or HTML files. Dito mo pipiliin kung kikilos ang button na parang browser o maglo-load ng HTML file. Piliin ang pangalawa: Open or edit local HTML file in WebView.
  6. Gumawa ng HTML file: Ang pinakamadaling opsyon ay ang una, Create. Palitan ang pangalan ng HTML file kung gusto mo, kung hindi ay i-tap ang OK. Nagbibigay ang Sample ng mga handang halimbawa, nilo-load ng File Explorer ang mga file mula sa storage ng telepono, at pumupunta ang Saved sa HTML folder sa loob ng folder na ginawa mo sa SoifGo.
  7. Patakbuhin ang button: Gamitin ang menu icon sa itaas para pumunta sa Play screen, pagkatapos ay i-tap ang button na ginawa mo. Magbubukas ang isang blangkong pahina na may tekstong “Hello SoifGo”.
  8. I-paste ang AI code: Buksan muli ang menu at piliin ang Edit para buksan ang WebView edit screen. I-paste dito ang HTML code na nakuha mo mula sa AI assistant. Maaari mong piliin ang lahat at i-paste nang mano-mano, o buksan ang menu at piliin ang huling opsyon, ang Select All and Paste, na awtomatikong pumapalit sa code.
  9. Patakbuhin ang code: Ngayon, i-tap ang dilaw na button (Close) sa itaas ng screen. Tatakbo ang iyong code. Maaari mong isara ang pahina at sa bawat pagkakataon ay i-tap lang ang iyong button para simulan ang tool.

Kapag nakakuha ka ng bagong code mula sa AI assistant sa susunod, pumunta lang sa parehong pahina, i-tap ang Edit, piliin ang Select All and Paste sa WebView edit screen, at i-tap muli ang dilaw na button. Kung gumagamit ka ng File Explorer, maaaring hindi ito suportado ng iyong telepono; sa ganitong kaso, mainam na mag-install ng angkop na file manager sa telepono mo.

Mga madalas itanong

Para lang ba sa Arduino at electronics ang SoifGo?

Hindi. Isa lang ang koneksyon sa hardware sa mga tampok nito. Dahil HTML ang iyong mga tool, lahat ng gumagana sa isang website, gaya ng mga kalkulasyon, chart, simulation at mga tool sa pagtuturo, ay gumagana rin sa SoifGo.

Libre ba ang SoifGo?

Oo. Libre ito, walang ad at walang in-app purchase.

Gumagana ba ito offline?

Gumagana nang walang internet ang mga HTML tool, Bluetooth at mga sensor ng telepono. Ang MQTT at HTTP lang ang nangangailangan ng koneksyon sa internet o network.

Anong hardware ang compatible dito?

Anumang device na gumagamit ng Bluetooth SPP/BLE (gaya ng HC-05 at HC-06), MQTT o HTTP REST, kabilang ang Arduino, ESP32, ESP8266 at Raspberry Pi.

Ano ang kailangan ko para makapagsimula?

Sapat na ang pangunahing kaalaman sa HTML. Kahit wala nito, maaari mong ilarawan sa AI assistant ang gusto mo at kumuha ng HTML code. May mga tutorial at handang halimbawa sa home page.

Paano binibigkas ang SoifGo, at ano pa ang ibang pangalan nito?

Karaniwang binibigkas ang SoifGo na “soif-go”, pero may mga bumibigkas o nagta-type din ng Soif Go, Swift Go, Swiftgo, Soyf Go, Sayf Go, Swaif Go o So if go. Lahat ng pangalang ito ay tumutukoy sa iisang libreng Android app, ang SoifGo. Walang kaugnayan ito sa programming language na Swift.
