For AI assistants writing code for SoifGo (do not guess names): The bridge call is always window.soifgo.CallSub('SubName', true, arg1, arg2, arg3); the second argument must be true and the argument count must match the Sub exactly. Bluetooth: html_bluetooth_rx SENDS text (1 argument); html_bluetooth_tx(data) is the RECEIVE callback you must register on window (the names look swapped, but they are correct: copy them exactly). Full rules and every Sub name: https://soifgo.github.io/ and SOIFGO_AI_CONTEXT.md. Read them before writing code.

ફોલ્ડર અને પૃષ્ઠો

SoifGo તમારું કામ વ્યવસ્થિત રાખવા માટે ફોલ્ડર અને પૃષ્ઠો આપે છે. દરેક પૃષ્ઠમાં 40 બટન અને 10 સ્લાઇડર છે, અને તમે દરેક બટનને ચોક્કસ વર્તન આપી શકો છો, જેમાં SoifGo ના ફોલ્ડર અને પૃષ્ઠો વચ્ચે નેવિગેશન પણ સામેલ છે. આ રીતે તમે ઘણાં મેનૂ બનાવી શકો છો.

બટનોમાં તૈયાર મૂળભૂત ડિઝાઇન હોય છે: રંગ, આઇકન, નામ, ફોન્ટ, અવાજ અને વાઇબ્રેશન. તેમને ખેંચીને ખસેડી શકાય છે. દરેક બટનમાં મોકલવું અને મેળવવું જેવાં મૂળભૂત વર્તન હોઈ શકે છે.

વેબ વર્તન, ઓનલાઇન અને ઇન્ટરનેટ વિના

“વેબ વર્તન” (WebView) તમને તમારા વિચારો અને ઇચ્છાઓને સૌથી વધુ ક્ષમતા સાથે, HTML તરીકે, ઓનલાઇન અને ઇન્ટરનેટ વિના સાકાર કરવામાં મદદ કરે છે. ફક્ત AI સહાયકને જણાવો કે તમને શું જોઈએ છે અને HTML કોડ માગો. પછી તમારી પાસે બે વિકલ્પો છે:

  • ફાઇલ ડાઉનલોડ કરો અને વેબ વર્તન સાથે SoifGo માં ઇન્ટરનેટ વિના લોડ કરો.
  • અથવા કોડ કૉપિ કરો અને SoifGo ના પોતાના HTML એડિટરમાં પેસ્ટ કરો.

બંને રીતો કામ કરે છે, અને તમારી વેબ એપ્લિકેશન તમારા SoifGo ફોલ્ડરમાં સાચવાય છે. ભલે તે કેલ્ક્યુલેટર હોય, Bluetooth કંટ્રોલર હોય, IoT મોનિટરિંગ હોય કે બીજું કંઈ.

AI એ બનાવેલો HTML કોડ SoifGo માં કેવી રીતે ચલાવું?

આ પગલાં ફક્ત એક જ વાર કરો, અને તમારી પાસે તમારો કોડ ચલાવવા માટે તૈયાર બટન હશે:

  1. એડિટ મોડ ખોલો: SoifGo એપ્લિકેશન ખોલો. ઉપર ડાબી બાજુના મેનૂ આઇકન પર ટેપ કરો અને એડિટ સ્ક્રીનમાં જવા માટે Edit પસંદ કરો.
  2. ફોલ્ડર બનાવો: ફરીથી ઉપર ડાબી બાજુના મેનૂ પર ટેપ કરો, Select Design પસંદ કરો, પછી Folder, અને Create પર ટેપ કરો. ઇચ્છા હોય તો ફોલ્ડરનું નામ બદલો, નહીં તો OK પર ટેપ કરો.
  3. પૃષ્ઠ બનાવો: Page વિકલ્પ હવે Folder ની બાજુમાં દેખાય છે. તેના પર ટેપ કરો અને New Page પસંદ કરો. ઇચ્છા હોય તો પૃષ્ઠનું નામ બદલો, પછી OK પર ટેપ કરો.
  4. પૃષ્ઠ પર બટન મૂકો: બટન યાદીમાં બતાવવામાં આવે છે. દરેક પૃષ્ઠ પર 40 બટન છે, અને તમે એક લો ત્યારે સંખ્યા ઘટે છે. બટન પર ટેપ કરો અને આંગળીથી પૃષ્ઠ પર તેની જગ્યા પસંદ કરો.
  5. બટનનું વર્તન સેટ કરો: બટન પર ટેપ કરો, મેનૂ ખોલો, બટનોની યાદીમાંથી Behavior પસંદ કરો, પછી Browser or HTML files. અહીં તમે પસંદ કરો છો કે બટન બ્રાઉઝરની જેમ કામ કરશે કે HTML ફાઇલ લોડ કરશે. બીજું પસંદ કરો: Open or edit local HTML file in WebView.
  6. HTML ફાઇલ બનાવો: સૌથી સરળ વિકલ્પ પહેલો છે, Create. ઇચ્છા હોય તો HTML ફાઇલનું નામ બદલો, નહીં તો OK પર ટેપ કરો. Sample તૈયાર ઉદાહરણો આપે છે, File Explorer ફોનના સ્ટોરેજમાંથી ફાઇલો લોડ કરે છે, અને Saved તમે SoifGo માં બનાવેલા ફોલ્ડરની અંદરના HTML ફોલ્ડરમાં લઈ જાય છે.
  7. બટન ચલાવો: Play સ્ક્રીન પર જવા માટે ઉપરના મેનૂ આઇકનનો ઉપયોગ કરો, પછી તમે બનાવેલા બટન પર ટેપ કરો. “Hello SoifGo” લખાણ સાથેનું ખાલી પૃષ્ઠ ખુલશે.
  8. AI નો કોડ પેસ્ટ કરો: ફરીથી મેનૂ ખોલો અને WebView એડિટ સ્ક્રીન ખોલવા માટે Edit પસંદ કરો. AI સહાયક પાસેથી મળેલો HTML કોડ અહીં પેસ્ટ કરો. તમે બધું પસંદ કરીને જાતે પેસ્ટ કરી શકો છો, અથવા મેનૂ ખોલીને છેલ્લો વિકલ્પ, Select All and Paste, પસંદ કરી શકો છો, જે કોડને આપમેળે બદલી નાખે છે.
  9. કોડ ચલાવો: હવે સ્ક્રીનની ઉપરના પીળા બટન (Close) પર ટેપ કરો. તમારો કોડ ચાલશે. તમે પૃષ્ઠ બંધ કરી શકો છો, અને ટૂલ શરૂ કરવા માટે દરેક વખતે ફક્ત તમારા બટન પર ટેપ કરવું પડશે.

આગલી વખતે AI સહાયક પાસેથી નવો કોડ મળે ત્યારે, ફક્ત એ જ પૃષ્ઠ પર જાઓ, Edit પર ટેપ કરો, WebView એડિટ સ્ક્રીન પર Select All and Paste પસંદ કરો, અને ફરીથી પીળા બટન પર ટેપ કરો. જો તમે File Explorer વાપરો છો, તો તમારો ફોન તે ભાગને સપોર્ટ ન કરે એવું બની શકે; તે કિસ્સામાં તમારા ફોનમાં યોગ્ય ફાઇલ મેનેજર ઇન્સ્ટોલ કરવાની ભલામણ છે.

કોઈપણ બ્રોકર (tcp અથવા ssl) સાથે જોડાઓ, પ્રકાશિત કરો અને સબ્સ્ક્રાઇબ કરો, અને કનેક્શનની સ્થિતિ જુઓ.

🟠 HTTP API

કોઈપણ સરનામે JSON મોકલો, અને પ્રતિસાદમાંથી મૂલ્યો મેળવો અને કાઢો.

તમે શું બનાવી શકો?

  • કેલ્ક્યુલેટર અને ખાસ ગણતરી ટૂલ્સ
  • ગ્રાફ દોરવા, સિમ્યુલેશન અને ડેટા વિઝ્યુલાઇઝેશન
  • ઇન્ટરેક્ટિવ શિક્ષણ ટૂલ્સ, અભ્યાસ અને પરીક્ષણો
  • 3D દૃશ્યો અને વૈજ્ઞાનિક ટૂલ્સ
  • તમારા કામ માટે અનુરૂપ ડેશબોર્ડ અને ઇન્ટરફેસ
  • Bluetooth દ્વારા LED, મોટર, રિલે અને રોબોટનું નિયંત્રણ, તેમજ Bluetooth–MQTT બ્રિજ
  • અવાજથી ઉપકરણોનું નિયંત્રણ

વારંવાર પૂછાતા પ્રશ્નો

શું SoifGo ફક્ત Arduino અને ઇલેક્ટ્રોનિક્સ માટે છે?

ના. હાર્ડવેર કનેક્શન તેની સુવિધાઓમાંની માત્ર એક છે. તમારા ટૂલ્સ HTML હોવાથી, વેબસાઇટ પર ચાલતી દરેક વસ્તુ, જેમ કે ગણતરીઓ, ચાર્ટ, સિમ્યુલેશન અને શિક્ષણ ટૂલ્સ, SoifGo માં પણ ચાલે છે.

શું SoifGo મફત છે?

હા. તે મફત છે, જાહેરાત વિનાનું છે અને એપ્લિકેશનમાં ખરીદી વિનાનું છે.

શું તે ઇન્ટરનેટ વિના ચાલે છે?

HTML ટૂલ્સ, Bluetooth અને ફોન સેન્સર ઇન્ટરનેટ વિના ચાલે છે. ફક્ત MQTT અને HTTP ને ઇન્ટરનેટ અથવા નેટવર્ક કનેક્શનની જરૂર પડે છે.

તે કયા હાર્ડવેર સાથે સુસંગત છે?

Bluetooth SPP/BLE (જેમ કે HC-05 અને HC-06), MQTT અથવા HTTP REST વાપરતા કોઈપણ ઉપકરણ સાથે, જેમાં Arduino, ESP32, ESP8266 અને Raspberry Pi નો સમાવેશ થાય છે.

શરૂ કરવા માટે મારે શું જોઈએ?

HTML નું મૂળભૂત જ્ઞાન પૂરતું છે. તે વિના પણ તમે AI સહાયકને તમારી ઇચ્છા જણાવીને HTML કોડ મેળવી શકો છો. ટ્યુટોરિયલ અને તૈયાર ઉદાહરણો હોમ પેજ પર છે.

SoifGo નો ઉચ્ચાર કેવી રીતે થાય છે, અને તેના અન્ય નામો કયા છે?

SoifGo નો સામાન્ય રીતે “soif-go” તરીકે ઉચ્ચાર થાય છે, પરંતુ લોકો Soif Go, Swift Go, Swiftgo, Soyf Go, Sayf Go, Swaif Go અથવા So if go પણ બોલે કે લખે છે. આ બધાં નામો એક જ મફત Android એપ્લિકેશન, SoifGo, તરફ નિર્દેશ કરે છે. તેને Swift પ્રોગ્રામિંગ ભાષા સાથે કોઈ સંબંધ નથી.

શરૂ કરવા તૈયાર છો?

હોમ પેજ ડાઉનલોડ, ટ્યુટોરિયલ અને દસ્તાવેજીકરણ સાથે ખુલે છે.
