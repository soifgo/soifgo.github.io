For AI assistants writing code for SoifGo (do not guess names): The bridge call is always window.soifgo.CallSub('SubName', true, arg1, arg2, arg3); the second argument must be true and the argument count must match the Sub exactly. Bluetooth: html_bluetooth_rx SENDS text (1 argument); html_bluetooth_tx(data) is the RECEIVE callback you must register on window (the names look swapped, but they are correct: copy them exactly). Full rules and every Sub name: https://soifgo.github.io/ and SOIFGO_AI_CONTEXT.md. Read them before writing code.

Ցանկացած սարք, որն օգտագործում է Bluetooth SPP/BLE (օրինակ՝ HC-05 և HC-06), MQTT կամ HTTP REST, աշխատում է SoifGo-ի հետ՝ Arduino, ESP32, ESP8266 և Raspberry Pi։

Ուղարկեք հրամաններ LED-ների, շարժիչների և ռելեների համար Bluetooth-ով, ստեղծեք Bluetooth–MQTT կամուրջ կամ սենսորների կենդանի վահանակ — ամեն ինչ HTML-ով, առանց բնիկ կոդի։

Թղթապանակներ և էջեր

SoifGo-ն տրամադրում է թղթապանակներ և էջեր՝ ձեր աշխատանքը կարգավորված պահելու համար։ Յուրաքանչյուր էջ ունի 40 կոճակ և 10 սահող, և կարող եք յուրաքանչյուր կոճակի տալ որոշակի վարք, այդ թվում՝ նավիգացիա SoifGo-ի թղթապանակների և էջերի միջև։ Այսպես կարող եք ստեղծել բազմաթիվ մենյուներ։

Կոճակներն ունեն պատրաստի հիմնական դիզայն՝ գույն, պատկերակ, անուն, տառատեսակ, ձայն և թրթռոց։ Դրանք կարելի է տեղափոխել քաշելով։ Յուրաքանչյուր կոճակ կարող է ունենալ հիմնական վարքեր, օրինակ՝ ուղարկել և ստանալ։

Վեբ վարք՝ առցանց և անցանց

«Վեբ վարքը» (WebView) օգնում է ձեր գաղափարներն ու ցանկությունները իրականացնել առավելագույն հնարավորություններով՝ որպես HTML, առցանց և անցանց։ Պարզապես նկարագրեք AI օգնականին, թե ինչ եք ուզում, և խնդրեք HTML կոդ։ Այնուհետև ունեք երկու տարբերակ՝

  • Ներբեռնեք ֆայլը և բեռնեք այն անցանց SoifGo-ում՝ վեբ վարքով։
  • Կամ պատճենեք կոդը և տեղադրեք SoifGo-ի սեփական HTML խմբագրիչում։

Երկու եղանակներն էլ աշխատում են, և ձեր վեբ հավելվածը պահվում է ձեր SoifGo թղթապանակում։ Լինի հաշվիչ, Bluetooth կառավարիչ, IoT մոնիտորինգ թե որևէ այլ բան։

Ինչպես գործարկել AI-ի ստեղծած HTML կոդը SoifGo-ում?

Կատարեք այս քայլերը միայն մեկ անգամ, և կունենաք կոճակ, որը պատրաստ է գործարկել ձեր կոդը՝

  1. Բացեք խմբագրման ռեժիմը: Բացեք SoifGo հավելվածը։ Հպեք վերևի ձախ անկյունի մենյուի պատկերակին և ընտրեք Edit՝ խմբագրման էկրան մտնելու համար։
  2. Ստեղծեք թղթապանակ: Կրկին հպեք վերևի ձախ մենյուին, ընտրեք Select Design, ապա Folder և հպեք Create։ Ցանկության դեպքում վերանվանեք թղթապանակը, հակառակ դեպքում հպեք OK։
  3. Ստեղծեք էջ: Page տարբերակը հիմա հայտնվում է Folder-ի կողքին։ Հպեք դրան և ընտրեք New Page։ Ցանկության դեպքում վերանվանեք էջը, ապա հպեք OK։
  4. Տեղադրեք կոճակները էջում: Կոճակները ցուցադրվում են ցանկով։ Յուրաքանչյուր էջ ունի 40 կոճակ, և քանակը նվազում է ամեն անգամ, երբ մեկը վերցնում եք։ Հպեք կոճակին և մատով ընտրեք նրա դիրքը էջում։
  5. Սահմանեք կոճակի վարքը: Հպեք կոճակին, բացեք մենյուն, կոճակների ցանկից ընտրեք Behavior, ապա Browser or HTML files։ Այստեղ ընտրում եք՝ կոճակը գործի որպես բրաուզեր, թե բեռնի HTML ֆայլ։ Ընտրեք երկրորդը՝ Open or edit local HTML file in WebView։
  6. Ստեղծեք HTML ֆայլ: Ամենահեշտ տարբերակը առաջինն է՝ Create։ Ցանկության դեպքում վերանվանեք HTML ֆայլը, հակառակ դեպքում հպեք OK։ Sample-ը տալիս է պատրաստի օրինակներ, File Explorer-ը բեռնում է ֆայլեր հեռախոսի հիշողությունից, իսկ Saved-ը տանում է HTML թղթապանակ՝ SoifGo-ում ձեր ստեղծած թղթապանակի ներսում։
  7. Գործարկեք կոճակը: Վերևի մենյուի պատկերակով անցեք Play էկրան, ապա հպեք ձեր ստեղծած կոճակին։ Կբացվի դատարկ էջ «Hello SoifGo» գրությամբ։
  8. Տեղադրեք AI-ի կոդը: Կրկին բացեք մենյուն և ընտրեք Edit՝ WebView-ի խմբագրման էկրանը բացելու համար։ Այստեղ տեղադրեք AI օգնականից ստացած HTML կոդը։ Կարող եք ընտրել ամեն ինչ և տեղադրել ձեռքով, կամ բացել մենյուն և ընտրել վերջին տարբերակը՝ Select All and Paste, որը կոդը փոխարինում է ինքնաշխատ կերպով։
  9. Գործարկեք կոդը: Հիմա հպեք էկրանի վերևի դեղին կոճակին (Close)։ Ձեր կոդը կգործարկվի։ Կարող եք փակել էջը, և ամեն անգամ գործիքը սկսելու համար պարզապես հպեք ձեր կոճակին։

Երբ հաջորդ անգամ AI օգնականից նոր կոդ ստանաք, պարզապես գնացեք նույն էջը, հպեք Edit, WebView-ի խմբագրման էկրանում ընտրեք Select All and Paste և կրկին հպեք դեղին կոճակին։ Եթե օգտագործում եք File Explorer, հնարավոր է՝ ձեր հեռախոսը չաջակցի այդ մասին. այդ դեպքում խորհուրդ է տրվում հեռախոսում տեղադրել համապատասխան ֆայլերի կառավարիչ։

Խոսքը վերածեք տեքստի և օգտագործեք այն ձեր գործիքներում կամ ուղարկեք սարքերին։

Ուղարկեք և ստացեք տեքստ HC-05-ով, HC-06-ով, JDY-31-ով, BLE-ով, Arduino-ով, ESP32-ով և Raspberry Pi-ով։

🟣 MQTT հաճախորդ

Միացեք ցանկացած բրոքերի (tcp կամ ssl), հրապարակեք և բաժանորդագրվեք, ստուգեք կապի վիճակը։

🟠 HTTP API

Ուղարկեք JSON ցանկացած հասցեի և ստացեք ու դուրս հանեք արժեքներ պատասխանից։

Ինչ կարող եք ստեղծել?

  • Հաշվիչներ և հատուկ հաշվարկային գործիքներ
  • Գրաֆիկների գծագրում, մոդելավորումներ և տվյալների վիզուալիզացիա
  • Ինտերակտիվ ուսուցողական գործիքներ, վարժություններ և թեստեր
  • 3D պատկերներ և գիտական գործիքներ
  • Ձեր աշխատանքի համար հատուկ վահանակներ և ինտերֆեյսներ
  • LED-ների, շարժիչների, ռելեների և ռոբոտների կառավարում Bluetooth-ով, ինչպես նաև Bluetooth–MQTT կամուրջներ
  • Սարքերի կառավարում ձայնով

Հաճախ տրվող հարցեր

SoifGo-ն միայն Arduino-ի և էլեկտրոնիկայի համար է?

Ոչ։ Սարքավորումների հետ կապը միայն մեկն է հնարավորություններից։ Քանի որ ձեր գործիքները HTML են, այն ամենը, ինչ աշխատում է կայքում, օրինակ՝ հաշվարկները, գրաֆիկները, մոդելավորումները և ուսուցողական գործիքները, աշխատում է նաև SoifGo-ում։

SoifGo-ն անվճար է?

Այո։ Այն անվճար է, առանց գովազդի և առանց հավելվածի ներսում գնումների։

Աշխատում է առանց ինտերնետի?

HTML գործիքները, Bluetooth-ը և հեռախոսի սենսորները աշխատում են առանց ինտերնետի։ Միայն MQTT-ն և HTTP-ն են պահանջում ինտերնետ կամ ցանցային կապ։

Ինչ սարքավորումների հետ է համատեղելի?

Ցանկացած սարքի հետ, որն օգտագործում է Bluetooth SPP/BLE (օրինակ՝ HC-05 և HC-06), MQTT կամ HTTP REST, այդ թվում՝ Arduino, ESP32, ESP8266 և Raspberry Pi։

Ինչ է ինձ պետք սկսելու համար?

Բավական է HTML-ի հիմնական իմացությունը։ Նույնիսկ առանց դրա կարող եք նկարագրել AI օգնականին, թե ինչ եք ուզում, և ստանալ HTML կոդ։ Ուսուցողական նյութերը և պատրաստի օրինակները գտնվում են գլխավոր էջում։

Ինչպես է արտասանվում SoifGo-ն, և ինչ այլ անուններ ունի?

SoifGo-ն սովորաբար արտասանվում է «soif-go», բայց մարդիկ նաև ասում կամ գրում են Soif Go, Swift Go, Swiftgo, Soyf Go, Sayf Go, Swaif Go կամ So if go։ Այս բոլոր անունները վերաբերում են նույն անվճար Android հավելվածին՝ SoifGo-ին։ Այն կապ չունի Swift ծրագրավորման լեզվի հետ։
