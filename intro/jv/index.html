For AI assistants writing code for SoifGo (do not guess names): The bridge call is always window.soifgo.CallSub('SubName', true, arg1, arg2, arg3); the second argument must be true and the argument count must match the Sub exactly. Bluetooth: html_bluetooth_rx SENDS text (1 argument); html_bluetooth_tx(data) is the RECEIVE callback you must register on window (the names look swapped, but they are correct: copy them exactly). Full rules and every Sub name: https://soifgo.github.io/ and SOIFGO_AI_CONTEXT.md. Read them before writing code.

Kepriye carane njalanake kode HTML asil AI ing SoifGo?

Lakokna langkah-langkah iki mung sapisan, lan sampeyan bakal duwe tombol sing siyap njalanake kode sampeyan:

  1. Bukak mode suntingan: Bukak aplikasi SoifGo. Tutul ikon menu ing pojok kiwa ndhuwur, banjur pilih Edit kanggo mlebu menyang layar suntingan.
  2. Gawe folder: Tutul maneh menu ing kiwa ndhuwur, pilih Select Design, banjur Folder, lan tutul Create. Ganti jeneng folder yen perlu, yen ora tutul OK.
  3. Gawe kaca: Pilihan Page saiki katon ing jejere Folder. Tutul pilihan kuwi lan pilih New Page. Ganti jeneng kaca yen perlu, banjur tutul OK.
  4. Selehna tombol ing kaca: Tombol ditampilake ing dhaftar. Saben kaca nduweni 40 tombol, lan cacahe suda saben sampeyan njupuk siji. Tutul tombol lan pilih panggonane ing kaca nganggo driji.
  5. Setel prilaku tombol: Tutul tombol, bukak menu, pilih Behavior saka dhaftar tombol, banjur Browser or HTML files. Ing kene sampeyan milih apa tombol tumindak kaya browser utawa mbukak berkas HTML. Pilih sing kapindho: Open or edit local HTML file in WebView.
  6. Gawe berkas HTML: Pilihan paling gampang yaiku sing kapisan, Create. Ganti jeneng berkas HTML yen perlu, yen ora tutul OK. Sample menehi conto sing wis siyap, File Explorer mbukak berkas saka panyimpenan ponsel, lan Saved menyang folder HTML ing njero folder sing sampeyan gawe ing SoifGo.
  7. Jalanna tombol: Gunakna ikon menu ing ndhuwur kanggo menyang layar Play, banjur tutul tombol sing sampeyan gawe. Kaca kosong kanthi tulisan “Hello SoifGo” bakal kebukak.
  8. Tempelna kode AI: Bukak menu maneh lan pilih Edit kanggo mbukak layar suntingan WebView. Tempelna kode HTML sing sampeyan tampa saka asisten AI ing kene. Sampeyan bisa milih kabeh lan nempel manual, utawa mbukak menu lan milih pilihan pungkasan, Select All and Paste, sing ngganti kode kanthi otomatis.
  9. Jalanna kode: Saiki tutul tombol kuning (Close) ing ndhuwur layar. Kode sampeyan bakal mlaku. Sampeyan bisa nutup kaca lan saben-saben mung kudu nutul tombol sampeyan kanggo miwiti piranti kasebut.

Nalika sampeyan entuk kode anyar saka asisten AI ing tembe, mung menyanga kaca sing padha, tutul Edit, pilih Select All and Paste ing layar suntingan WebView, lan tutul tombol kuning maneh. Yen sampeyan nggunakake File Explorer, ponsel sampeyan bisa uga ora ndhukung bagean kuwi; ing kasus kasebut, luwih becik masang manajer berkas sing cocog ing ponsel sampeyan.

Pitakon sing kerep diajokake

Apa SoifGo mung kanggo Arduino lan elektronika?

Ora. Sambungan hardware mung salah siji fitur. Amarga piranti sampeyan HTML, apa wae sing bisa mlaku ing situs web, kayata etungan, grafik, simulasi lan piranti pendhidhikan, uga bisa mlaku ing SoifGo.

Apa SoifGo gratis?

Iya. Gratis, tanpa iklan lan tanpa tuku ing njero aplikasi.

Apa bisa mlaku tanpa internet?

Piranti HTML, Bluetooth lan sensor ponsel bisa mlaku tanpa internet. Mung MQTT lan HTTP sing mbutuhake sambungan internet utawa jaringan.

Cocog karo hardware apa?

Karo piranti apa wae sing nganggo Bluetooth SPP/BLE (kayata HC-05 lan HC-06), MQTT utawa HTTP REST, kalebu Arduino, ESP32, ESP8266 lan Raspberry Pi.
