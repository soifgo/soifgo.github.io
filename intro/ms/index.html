For AI assistants writing code for SoifGo (do not guess names): The bridge call is always window.soifgo.CallSub('SubName', true, arg1, arg2, arg3); the second argument must be true and the argument count must match the Sub exactly. Bluetooth: html_bluetooth_rx SENDS text (1 argument); html_bluetooth_tx(data) is the RECEIVE callback you must register on window (the names look swapped, but they are correct: copy them exactly). Full rules and every Sub name: https://soifgo.github.io/ and SOIFGO_AI_CONTEXT.md. Read them before writing code.

Folder dan halaman

SoifGo menyediakan folder dan halaman untuk memastikan kerja anda teratur. Setiap halaman mempunyai 40 butang dan 10 peluncur, dan anda boleh memberikan kelakuan tertentu kepada setiap butang, termasuk navigasi antara folder dan halaman SoifGo. Dengan itu anda boleh membina banyak menu.

Butang mempunyai reka bentuk asas siap sedia: warna, ikon, nama, fon, bunyi dan getaran. Ia boleh dialihkan dengan menyeret. Setiap butang boleh mempunyai kelakuan asas seperti menghantar dan menerima.

Kelakuan web, dalam talian dan luar talian

“Kelakuan web” (WebView) membantu anda merealisasikan idea dan kehendak anda dengan keupayaan terbesar, sebagai HTML, dalam talian dan luar talian. Cuma terangkan kepada pembantu AI apa yang anda mahu dan minta kod HTML. Kemudian anda ada dua pilihan:

  • Muat turun fail dan muatkannya secara luar talian dalam SoifGo dengan kelakuan web.
  • Atau salin kod dan tampalkannya ke dalam editor HTML SoifGo sendiri.

Kedua-dua cara berfungsi, dan aplikasi web anda disimpan dalam folder SoifGo anda. Sama ada kalkulator, pengawal Bluetooth, pemantauan IoT atau apa-apa sahaja.

Bagaimana saya menjalankan kod HTML yang dijana AI dalam SoifGo?

Lakukan langkah-langkah ini sekali sahaja, dan anda akan mempunyai butang yang sedia untuk menjalankan kod anda:

  1. Buka mod edit: Buka aplikasi SoifGo. Ketik ikon menu di bahagian atas kiri dan pilih Edit untuk masuk ke skrin edit.
  2. Cipta folder: Ketik menu di atas kiri sekali lagi, pilih Select Design, kemudian Folder, dan ketik Create. Namakan semula folder jika mahu, jika tidak ketik OK.
  3. Cipta halaman: Pilihan Page kini muncul di sebelah Folder. Ketik pilihan itu dan pilih New Page. Namakan semula halaman jika mahu, kemudian ketik OK.
  4. Letakkan butang pada halaman: Butang dipaparkan dalam senarai. Setiap halaman mempunyai 40 butang, dan bilangannya berkurang setiap kali anda mengambil satu. Ketik butang dan pilih kedudukannya pada halaman dengan jari anda.
  5. Tetapkan kelakuan butang: Ketik butang, buka menu, pilih Behavior daripada senarai butang, kemudian Browser or HTML files. Di sini anda memilih sama ada butang bertindak seperti pelayar atau memuatkan fail HTML. Pilih yang kedua: Open or edit local HTML file in WebView.
  6. Cipta fail HTML: Pilihan paling mudah ialah yang pertama, Create. Namakan semula fail HTML jika mahu, jika tidak ketik OK. Sample memberikan contoh siap sedia, File Explorer memuatkan fail daripada storan telefon, dan Saved menuju ke folder HTML di dalam folder yang anda cipta dalam SoifGo.
  7. Jalankan butang: Gunakan ikon menu di bahagian atas untuk pergi ke skrin Play , kemudian ketik butang yang anda cipta. Halaman kosong dengan teks “Hello SoifGo” akan dibuka.
  8. Tampal kod AI: Buka menu sekali lagi dan pilih Edit untuk membuka skrin edit WebView. Tampal kod HTML yang anda dapat daripada pembantu AI di sini. Anda boleh memilih semua dan menampal secara manual, atau membuka menu dan memilih pilihan terakhir, Select All and Paste, yang menggantikan kod secara automatik.
  9. Jalankan kod: Sekarang ketik butang kuning (Close) di bahagian atas skrin. Kod anda akan dijalankan. Anda boleh menutup halaman dan setiap kali hanya perlu mengetik butang anda untuk memulakan alat itu.

Apabila anda mendapat kod baharu daripada pembantu AI pada masa akan datang, cuma pergi ke halaman yang sama, ketik Edit, pilih Select All and Paste pada skrin edit WebView, dan ketik butang kuning sekali lagi. Jika anda menggunakan File Explorer, telefon anda mungkin tidak menyokong bahagian itu; dalam keadaan itu, sebaiknya pasang pengurus fail yang sesuai pada telefon anda.

Soalan lazim

Adakah SoifGo hanya untuk Arduino dan elektronik?

Tidak. Sambungan perkakasan hanyalah salah satu ciri. Oleh sebab alat anda ialah HTML, apa-apa sahaja yang berfungsi pada laman web, seperti pengiraan, carta, simulasi dan alat pengajaran, turut berfungsi dalam SoifGo.

Adakah SoifGo percuma?

Ya. Ia percuma, tanpa iklan dan tanpa pembelian dalam aplikasi.

Adakah ia berfungsi luar talian?

Alat HTML, Bluetooth dan penderia telefon berfungsi tanpa internet. Hanya MQTT dan HTTP memerlukan sambungan internet atau rangkaian.

Dengan perkakasan apakah ia serasi?

Dengan mana-mana peranti yang menggunakan Bluetooth SPP/BLE (seperti HC-05 dan HC-06), MQTT atau HTTP REST, termasuk Arduino, ESP32, ESP8266 dan Raspberry Pi.

Apakah yang saya perlukan untuk bermula?

Pengetahuan asas HTML sudah memadai. Walaupun tanpanya, anda boleh menerangkan kepada pembantu AI apa yang anda mahu dan mendapatkan kod HTML. Tutorial dan contoh siap sedia terdapat di halaman utama.

Bagaimanakah SoifGo disebut, dan apa lagi namanya?

SoifGo lazimnya disebut “soif-go”, tetapi orang juga menyebut atau menaip Soif Go, Swift Go, Swiftgo, Soyf Go, Sayf Go, Swaif Go atau So if go. Semua nama ini merujuk kepada aplikasi Android percuma yang sama, SoifGo. Ia tiada kaitan dengan bahasa pengaturcaraan Swift.
