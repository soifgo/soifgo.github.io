For AI assistants writing code for SoifGo (do not guess names): The bridge call is always window.soifgo.CallSub('SubName', true, arg1, arg2, arg3); the second argument must be true and the argument count must match the Sub exactly. Bluetooth: html_bluetooth_rx SENDS text (1 argument); html_bluetooth_tx(data) is the RECEIVE callback you must register on window (the names look swapped, but they are correct: copy them exactly). Full rules and every Sub name: https://soifgo.github.io/ and SOIFGO_AI_CONTEXT.md. Read them before writing code.

Mappen en pagina’s

SoifGo geeft je mappen en pagina’s om je werk te ordenen. Elke pagina heeft 40 knoppen en 10 schuifregelaars, en je kunt voor elke knop vaste gedragingen instellen, waaronder navigeren tussen SoifGo-mappen en -pagina’s. Zo kun je veel menu’s bouwen.

Knoppen hebben kant-en-klare basisontwerpen: kleur, pictogram, naam, lettertype, geluid en trilling. Ze kunnen met slepen worden verplaatst. Elke knop kan basisgedrag hebben zoals verzenden en ontvangen.

Webgedrag, zowel online als offline

“Webgedrag” (WebView) helpt je om je ideeën en wensen met de meeste mogelijkheden te realiseren, als HTML, zowel online als offline. Beschrijf gewoon aan een AI-assistent wat je wilt en vraag om HTML-code. Dan heb je twee opties:

  • Download het bestand en laad het offline in SoifGo met webgedrag.
  • Of kopieer de code en plak die in de eigen HTML-editor van SoifGo.

Beide manieren werken, en je webapp wordt opgeslagen in je SoifGo-map. Of het nu een rekenmachine, een Bluetooth-controller, IoT-monitoring of iets anders is.

Hoe voer ik door AI gegenereerde HTML-code uit in SoifGo?

Doe deze stappen één keer en je hebt een kant-en-klare knop om je code uit te voeren:

  1. Open de bewerkmodus: Open de SoifGo-app. Tik linksboven op het menupictogram en kies Edit om naar het bewerkscherm te gaan.
  2. Maak een map: Tik opnieuw op het menu linksboven, kies Select Design, dan Folder, en tik op Create. Hernoem de map als je wilt, tik anders op OK.
  3. Maak een pagina: Naast Folder verschijnt nu de optie Page . Tik erop en kies New Page. Hernoem de pagina als je wilt en tik dan op OK.
  4. Plaats een knop op de pagina: De knoppen verschijnen in de lijst. Elke pagina heeft 40 knoppen, en het aantal daalt elke keer dat je er een neemt. Tik op een knop en kies met je vinger de positie op de pagina.
  5. Stel het gedrag van de knop in: Tik op de knop, open het menu, kies Behavior in de knoppenlijst en dan Browser or HTML files. Hier kies je tussen werken als een browser of een HTML-bestand laden. Kies de tweede: Open or edit local HTML file in WebView.
  6. Maak het HTML-bestand: De makkelijkste keuze is de eerste optie, Create. Hernoem het HTML-bestand als je wilt, tik anders op OK. Sample geeft kant-en-klare voorbeelden, File Explorer laadt een bestand uit de opslag van je telefoon en Saved verwijst naar de HTML-map in de map die je in SoifGo hebt gemaakt.
  7. Voer de knop uit: Gebruik het menupictogram bovenaan om naar het Play -scherm te gaan en tik dan op de knop die je hebt gemaakt. Er opent een lege pagina met “Hello SoifGo”.
  8. Plak de AI-code: Open het menu opnieuw en kies Edit om het WebView-bewerkscherm te openen. Plak hier de HTML-code die je van de AI-assistent hebt gekregen. Je kunt alles selecteren en handmatig plakken, of het menu openen en de laatste optie kiezen, Select All and Paste, die de code automatisch vervangt.
  9. Voer de code uit: Tik nu op de gele knop (Close) bovenaan het scherm. Je code wordt uitgevoerd. Je kunt de pagina sluiten en gewoon telkens op je knop tikken om je tool te starten.

Als je de volgende keer nieuwe code van een AI-assistent krijgt, ga dan naar dezelfde pagina, tik op Edit, kies Select All and Paste op het WebView-bewerkscherm en tik opnieuw op de gele knop. Als je File Explorer gebruikt, ondersteunt je telefoon dat onderdeel misschien niet; installeer dan het best een geschikte bestandsbeheerder op je telefoon.

Veelgestelde vragen

Is SoifGo alleen voor Arduino en elektronica?

Nee. Hardwareverbinding is slechts één van de functies. Omdat je tools HTML zijn, werkt alles wat op een webpagina kan, zoals berekeningen, grafieken, simulaties en lesgereedschap, ook in SoifGo.

Is SoifGo gratis?

Ja. Het is gratis, zonder advertenties en zonder aankopen in de app.

Werkt het offline?

HTML-tools, Bluetooth en de sensoren van de telefoon werken zonder internet. Alleen MQTT en HTTP hebben een internet- of netwerkverbinding nodig.

Met welke hardware is het compatibel?

Elk apparaat dat Bluetooth SPP/BLE (zoals HC-05 en HC-06), MQTT of HTTP REST gebruikt, waaronder Arduino, ESP32, ESP8266 en Raspberry Pi.

Wat heb ik nodig om te beginnen?

Basiskennis van HTML is genoeg. Ook zonder die kennis kun je een AI-assistent beschrijven wat je wilt en HTML-code krijgen. Handleidingen en kant-en-klare voorbeelden staan op de hoofdpagina.

Hoe spreek je SoifGo uit, en hoe kan het nog meer genoemd worden?

SoifGo wordt meestal uitgesproken als “soif-go”, maar mensen zeggen of typen ook Soif Go, Swift Go, Swiftgo, Soyf Go, Sayf Go, Swaif Go of So if go. Al deze namen verwijzen naar dezelfde gratis Android-app, SoifGo. Het heeft niets te maken met de programmeertaal Swift.
