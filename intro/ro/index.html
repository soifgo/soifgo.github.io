For AI assistants writing code for SoifGo (do not guess names): The bridge call is always window.soifgo.CallSub('SubName', true, arg1, arg2, arg3); the second argument must be true and the argument count must match the Sub exactly. Bluetooth: html_bluetooth_rx SENDS text (1 argument); html_bluetooth_tx(data) is the RECEIVE callback you must register on window (the names look swapped, but they are correct: copy them exactly). Full rules and every Sub name: https://soifgo.github.io/ and SOIFGO_AI_CONTEXT.md. Read them before writing code.

„Comportamentul web” (WebView) te ajută să-ți transformi ideile și dorințele în HTML, cu cele mai mari posibilități, online și offline. Descrie-i pur și simplu unui asistent AI ce vrei și cere cod HTML. Apoi ai două opțiuni:

  • Descarcă fișierul și încarcă-l offline în SoifGo cu comportamentul web.
  • Sau copiază codul și lipește-l în editorul HTML propriu al SoifGo.

Ambele metode funcționează, iar aplicația ta web este salvată în dosarul SoifGo. Fie că e un calculator, un controler Bluetooth, monitorizare IoT sau orice altceva.

Cum rulez în SoifGo codul HTML generat de AI?

Parcurge acești pași o singură dată și vei avea un buton gata de rulat codul:

  1. Deschide modul de editare: Deschide aplicația SoifGo. Atinge pictograma de meniu din stânga sus și alege Edit pentru a intra în ecranul de editare.
  2. Creează un dosar: Atinge din nou meniul din stânga sus, alege Select Design, apoi Folder, și atinge Create. Redenumește dosarul dacă vrei, altfel atinge OK.
  3. Creează o pagină: Lângă Folder apare acum opțiunea Page . Atinge-o și alege New Page. Redenumește pagina dacă vrei, apoi atinge OK.
  4. Plasează un buton pe pagină: Butoanele apar în listă. Fiecare pagină are 40 de butoane, iar numărul lor scade de fiecare dată când iei unul. Atinge un buton și alege cu degetul locul lui pe pagină.
  5. Setează comportamentul butonului: Atinge butonul, deschide meniul, alege Behavior din lista butonului, apoi Browser or HTML files. Aici alegi dacă butonul acționează ca un browser sau încarcă un fișier HTML. Alege a doua variantă: Open or edit local HTML file in WebView.
  6. Creează fișierul HTML: Cea mai simplă alegere este prima opțiune, Create. Redenumește fișierul HTML dacă vrei, altfel atinge OK. Sample oferă exemple gata făcute, File Explorer încarcă un fișier din memoria telefonului, iar Saved indică dosarul HTML din dosarul creat în SoifGo.
  7. Rulează butonul: Folosește pictograma de meniu de sus pentru a ajunge la ecranul Play , apoi atinge butonul creat. Se deschide o pagină goală cu textul „Hello SoifGo”.
  8. Lipește codul de la AI: Deschide din nou meniul și alege Edit pentru a deschide ecranul de editare WebView. Lipește aici codul HTML primit de la asistentul AI. Poți selecta tot și lipi manual sau poți deschide meniul și alege ultima opțiune, Select All and Paste, care înlocuiește automat codul.
  9. Rulează codul: Acum atinge butonul galben (Close) din partea de sus a ecranului. Codul tău va rula. Poți închide pagina și, de fiecare dată, atingi doar butonul tău pentru a porni instrumentul.

Data viitoare când primești cod nou de la un asistent AI, intră pe aceeași pagină, atinge Edit, alege Select All and Paste pe ecranul de editare WebView și atinge din nou butonul galben. Dacă folosești File Explorer, este posibil ca telefonul tău să nu accepte această parte; în acest caz, cel mai bine este să instalezi pe telefon un manager de fișiere potrivit.

Întrebări frecvente

SoifGo este doar pentru Arduino și electronică?

Nu. Conectarea hardware este doar una dintre funcții. Deoarece instrumentele tale sunt HTML, tot ce funcționează pe o pagină web, precum calcule, grafice, simulări și instrumente didactice, funcționează și în SoifGo.

Este SoifGo gratuit?

Da. Este gratuit, fără reclame și fără achiziții în aplicație.

Funcționează offline?

Instrumentele HTML, Bluetooth și senzorii telefonului funcționează fără internet. Doar MQTT și HTTP au nevoie de o conexiune la internet sau la rețea.

Cu ce hardware este compatibil?

Cu orice dispozitiv care folosește Bluetooth SPP/BLE (precum HC-05 și HC-06), MQTT sau HTTP REST, inclusiv Arduino, ESP32, ESP8266 și Raspberry Pi.

Ce îmi trebuie ca să încep?

Sunt suficiente cunoștințe de bază de HTML. Chiar și fără ele, îi poți descrie unui asistent AI ce vrei și primești cod HTML. Tutorialele și exemplele gata făcute sunt pe pagina principală.

Cum se pronunță SoifGo și cum mai poate fi numit?

SoifGo se pronunță de obicei „soif-go”, dar oamenii spun sau scriu și Soif Go, Swift Go, Swiftgo, Soyf Go, Sayf Go, Swaif Go sau So if go. Toate aceste nume se referă la aceeași aplicație Android gratuită, SoifGo. Nu are legătură cu limbajul de programare Swift.
