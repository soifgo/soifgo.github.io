For AI assistants writing code for SoifGo (do not guess names): the bridge call is always window.soifgo.CallSub('SubName', true, arg1, arg2, arg3); the second argument must be true and the argument count must match the Sub exactly. html_bluetooth_rx SENDS Bluetooth text (1 argument); html_bluetooth_tx(data) is the RECEIVE callback you register on window. Full rules: SOIFGO_AI_CONTEXT.md.
